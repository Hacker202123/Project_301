# 🛡️ Multi-User OSINT Graph Platform

Полнофункциональная самохостящаяся многопользовательская платформа для проведения OSINT-расследований с визуализацией связей в виде интерактивных графов. Проект разработан на чистом Python и использует библиотеку `vis-network`.

---

## 🚀 Основные возможности

* **🛡️ Безопасная аутентификация:** Раздельные сеансы для каждого пользователя с хэшированием паролей (SHA-256) и изоляцией данных в персональных JSON-файлах.
* **🌐 40 встроенных OSINT-инструментов:** Проверка IP-геолокации, DNS-записей (A, AAAA, MX, TXT), профилей GitHub, NPM, PyPI, Steam, Reddit, HackerNews, криптокошельков (BTC, ETH), уязвимостей CVE и многое другое.
* **🖼️ Динамический движок изображений:** Автоматическая конвертация и масштабирование загружаемых изображений в фиксированный закругленный квадрат `512x512` с точными хитбоксами под визуальные границы.
* **🔗 Управление графом:** Ручное связывание узлов с кастомными подписями, удаление узлов/связей и поддержка прокси-маршрутизации (HTTP/SOCKS5).
* **📦 Удобство развертывания:** Работает на стандартном Python без тяжеловесных фреймворков.
